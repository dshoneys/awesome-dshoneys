HOW IT WORKS

从提交到收录

  1. 01提交插件

    通过 Issue 或 Pull Request 提供公开链接与基本信息。

  2. 02安全检测

    检查权限、代码、数据、密钥和第三方依赖风险。

  3. 03作者修复

    发现问题先联系作者，完成修复后再进行复检。

  4. 04认证收录

    展示安全徽章、检测报告与真实使用反馈。
