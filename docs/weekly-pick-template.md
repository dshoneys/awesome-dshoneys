# 每周精选模板

本模板用于 `weekly-picks/` 目录下的周报文件（如 `weekly-picks/2026-W34.md`）。每周五由 GitHub Actions 定时提醒生成，负责人按本模板填写后提交，并在 README 的「每周精选」章节挂上链接。

---

## 模板正文（复制以下内容，替换所有 `<>` 占位）

```markdown
# DeepSeek Honeys 插件目录 · 每周精选

**第 N 期 · 2026-08-21**（覆盖 2026-08-15 ~ 2026-08-21）

> 一句话开篇：本期看点（例：本期主打数据接入类插件，两个新面孔全部通过安全检测）。

---
```

## 填写说明（不随模板复制）

1. **期数与日期**：期数从第 1 期起连续编号，不跳号；日期用该周五的日期（ISO 格式 `YYYY-MM-DD`）。
2. **精选数量**：3-5 个，不足 3 个时可注明「本周投稿较少」，但不要降低检测门槛凑数。
3. **徽章与报告**：精选条目必须已出安全报告并挂徽章（✅/⚠️），❌ 不通过的插件不上榜。
4. **一句话点评**：控制在一句话（约 50 字内），讲清「解决什么问题 + 适合谁」，避免营销式夸赞。
5. **需求墙进展**：每周五统计一次 label 为 `request-plugin` 的 Issues；状态用 🟢 已认领 / 🟡 待认领 / ✅ 已完成。
6. **下期预告**：可以只写一句占位，避免空头承诺。
